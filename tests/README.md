# 🧪 Testing Framework

## Overview
Comprehensive testing suite for the Imarika Agricultural AI Assistant.

## Structure
```
tests/
├── unit/
│   └── simple_test.py       # Basic functionality tests
└── integration/
    ├── test_enhanced.py     # Enhanced system tests
    └── evaluate_system.py  # System evaluation tests
```

## Usage
```bash
# Run unit tests
python tests/unit/simple_test.py

# Run integration tests
python tests/integration/test_enhanced.py
python tests/integration/evaluate_system.py
```
